# Dost AI build brief

Dost is a premium but restrained AI operating workspace. It should feel closer to a calm futuristic command surface than a dashboard full of widgets.

Core users:
- developers
- cybersecurity learners
- students
- job seekers / career builders
- people building websites and projects with natural-language prompts

Core behavior:
- general AI assistant
- conversation context
- file/document attachment
- defensive cybersecurity mode
- code/problem solving
- study planning
- CV-to-job discovery
- AI project generation

Visual direction:
- deep black / purple base
- restrained violet and cyan highlights
- glass panels only where useful
- one persistent lightweight Canvas field behind all sections
- background responds subtly to mouse and scroll
- no giant visual dashboard filling the viewport
- mobile automatically reduces particles and motion

The job feature is an aggregator layer. Use approved APIs/feeds such as Adzuna, Arbeitnow, Remotive and optional licensed providers. Never put provider secrets in the browser.

# Karo AI — Final Visual Front-End

## New in this final package
- Full-page animated AI/network background.
- Visual hero AI core.
- Visual Developer, Cyber, Study and Career cards.
- Clickable cards + live workspace.
- **Real prompt/composer UI** where the user can type a task for Karo.
- Auto / Study / Code / Cyber / Career mode selector.
- File attachment button for CV/code/document selection.
- Send button with front-end response state.
- Ctrl/Cmd + Enter submits the prompt.
- Ready to connect to a real AI backend/API later.

## Important
The prompt box is currently a **front-end interface/demo**. It does not call an AI API yet. The exact place to connect your backend is marked in `script.js` under:

`// Karo AI prompt composer — front-end demo layer.`

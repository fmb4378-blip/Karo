# Karo AI Landing Page

This version is intentionally self-contained: the hero AI visualization is built with CSS/HTML, so there is no broken external image dependency.

## Upload to GitHub Pages / Cloudflare

Upload these files while keeping the structure:

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

Open `index.html` or deploy the repository as a static site.

## Important

The animated Karo Core, orbit rings, particles, floating capability panels, scroll reveals, card tilt and responsive mobile layout are all included directly in the code.

# Karo AI — Final Landing Page

This package is a self-contained upgraded landing page for Karo AI.

## Included
- `index.html` — complete landing page
- `style.css` — responsive cinematic UI, glass panels, glow, 3D-like depth
- `app.js` — scroll reveal, scroll progress, floating cards, tilt cards, story-step activation and interactive live workspace preview
- `assets/` — local SVG visual assets for Hero, Cyber Lab, Study Mentor, Career Navigator and background grid

## Run
Open `index.html` directly in a browser, or deploy the folder to GitHub Pages / Cloudflare Pages.

## Making the demo truly AI-powered
The live workspace is intentionally frontend-only. Connect your preferred AI backend/API inside `app.js` or through your own server endpoint. For CV/job matching, keep CV processing and external job-source integrations on a secure backend rather than exposing API keys in the browser.

## Design direction
The old robot has been replaced by an abstract AI core. Sections use visual backgrounds, floating glass cards, depth/tilt effects and scroll-triggered transitions so the page feels more like a premium product experience than a static template.

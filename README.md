# Karo — AI Copilot Landing Page

Cinematic landing page for an AI copilot aimed at students, developers, cybersecurity learners and curious builders.

## Files
- `index.html` — landing page
- `style.css` — responsive visual system
- `script.js` — interactions and Live Lab demo
- `wrangler.toml` — Cloudflare static assets configuration

## Deploy
```bash
npx wrangler deploy
```

The Live Lab is a frontend demo. Connect your preferred AI/backend API later for real responses.
